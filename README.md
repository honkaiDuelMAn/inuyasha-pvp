# 이누야샤 데몬 토너먼트 · 1대1 PvP

원본 Flash 게임을 Ruffle로 실행하며, 친구와 1대1 대전할 수 있습니다.

웹 주소: https://honkaiDuelMAn.github.io/inuyasha-pvp/

## 웹에서 친구와 대전하기

1. 두 사람이 웹페이지를 엽니다.
2. 호스트가 **방 만들기**를 누르고, **전체 초대 코드**를 복사해 상대에게 개인적으로 보냅니다.
3. 참가자는 초대 코드를 붙여 넣고 **참가**를 누릅니다. 생성된 **전체 응답 코드**를 3분 안에 호스트에게 보냅니다.
4. 호스트가 응답 코드를 붙여 넣고 **응답 적용 · 연결**을 누릅니다.
5. 각자 게임 화면에서 PLAY → NORMAL 또는 HARD → 캐릭터 선택 후 **준비 완료**를 누릅니다.
6. 경기 종료 후 양쪽이 **캐릭터 다시 선택**을 누르면 같은 연결로 재대전합니다.

방을 만든 사람의 브라우저가 방과 대전을 관리합니다. 이 사이트를 배포한 사람의 PC는 꺼져 있어도 됩니다. 호스트가 페이지를 닫으면 해당 방은 종료됩니다.

## 짧아진 연결 코드 (1.1.1)

새 초대·응답 코드는 `IY2-`로 시작합니다. 연결 정보를 손실 없이 압축하며, 실제 Chrome 검사에서 약 965자에서 320자 안팎으로 약 67% 짧아졌습니다. 네트워크에 따라 실제 길이는 달라집니다. 페이지를 새로고침한 뒤 방을 만들면 적용됩니다.

기존 `IY1-` 코드도 입력할 수 있습니다. 기존 긴 초대에 참가하면 이전 호스트가 읽을 수 있는 긴 응답을 돌려줍니다. 양쪽이 페이지를 새로고침하면 짧은 코드를 사용합니다. 초대·응답 교환 순서는 그대로이며 외부 연결 서버는 추가하지 않습니다.

## 연결 범위

GitHub Pages는 게임 파일만 제공합니다. 게임은 별도 방 서버, 신호 교환 서버, STUN 또는 TURN 서버에 접속하지 않습니다. 두 사람이 초대·응답 코드를 직접 전달해 연결 정보를 교환합니다. 6자리 방 번호만으로 다른 브라우저를 찾을 수는 없습니다.

**서로 다른 인터넷 회선에서는 공유기/NAT와 브라우저의 주소 제한으로 직접 연결이 실패할 수 있습니다. 모든 네트워크에서 접속을 보장하지 않습니다.** 같은 네트워크에서는 연결하기 쉽습니다. 외부 연결 서버를 전혀 사용하지 않는 조건에 따른 제한입니다. 연결이 안 되면 취소 후 코드를 새로 교환하세요. 이 방법도 공유기 차단을 해제하지는 않습니다.

두 개의 독립된 로컬 브라우저와 실제 Pages 주소에서 연결 및 원본 전투를 검증합니다. 다른 외부 PC 두 대 사이의 연결은 이 환경에서 검증하지 못했습니다.

## 게임 규칙

- 호스트가 추가카드 0~3장을 설정합니다. 0장이면 추가카드 추첨을 하지 않습니다.
- 1~3장은 선택한 두 캐릭터가 원본에서 함께 쓸 수 있는 추가카드 중 중복 없이 추첨하며 양쪽에 같은 목록을 지급합니다.
- 원본 캐릭터, 행동 카드, 전투 판정과 애니메이션을 사용합니다. 양쪽의 판정이 다르면 대전을 종료합니다.
- 대전 중 타이틀 음악은 원본 대전 진입 방식에 맞춰 정지합니다.

## 소스와 실행

`public/direct.html`은 서버 없는 웹 버전입니다. `python tools/pages.py 대상폴더`로 정적 배포 파일을 만듭니다. `file://`로 직접 여는 대신 HTTPS 정적 호스팅 또는 개발용 localhost 웹서버를 사용하세요. GitHub Actions가 `pvp` 브랜치의 정적 파일을 Pages로 배포합니다.

기존 Windows 호스트 프로그램/Node 버전은 `public/index.html`을 계속 사용합니다. 해당 방식은 호스트 프로그램 실행이 필요합니다. 이전 배포 폴더와 ZIP은 별도로 보존했습니다.

구성요소 출처와 라이선스는 [THIRD-PARTY.txt](THIRD-PARTY.txt)를 참고하세요. 게임 리소스의 저작권은 원권리자에게 있습니다.
