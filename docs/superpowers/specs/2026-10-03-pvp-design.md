# 이누야샤 PvP 설계

사용자는 원본을 유지한 1대1 대전을 요청했고, 각자 다른 PC의 방 생성·참가를 확인했다. 엔진 선택과 구현 진행은 사용자에게 위임받았다.

원본 SWF의 모든 기존 태그를 보존하고 게임 초기화 뒤 PvP 분기를 추가한다. 원본 모드는 수정하지 않은 game-original.swf를 실행한다. Ruffle을 로컬 패키지에 포함하고 방 서버를 호스트 PC에서 실행한다. 참가자는 동일 서버의 주소와 방 코드로 접속한다. 같은 네트워크 및 VPN 주소로 실행할 수 있으며 인터넷 외부 접속에는 호스트 서버에 도달 가능한 네트워크가 필요하다. 공개 서비스 배포는 이 작업에 포함하지 않는다.

방은 호스트 1P, 참가자 2P만 허용한다. 두 플레이어는 원래 화면에서 캐릭터를 선택한다. 둘 다 준비하면 새 경기 번호를 부여한다. 같은 캐릭터 선택도 허용한다. 호스트는 경기 전 추가카드 0~3장을 설정한다. 0장이면 난수 호출 없이 빈 목록을 사용한다. 1~3장은 두 캐릭터에 원래 호환되는 추가카드에서 중복 없이 한 번 추첨한다. 목록을 두 플레이어에게 각각 지급하며 경기 중에는 다시 추첨하지 않는다. 다음 경기 시작에 다시 추첨한다. 전용 카드 범위의 결정은 원본 캐릭터 제한 보존을 우선한 구현 판단이다.

플레이어는 원래 규칙대로 서로 다른 카드 3장을 선택한다. 상대 제출 전 입력을 공개하지 않는다. 두 입력을 모두 확정한 뒤 양쪽 원본 엔진에 같은 1P/2P 순서로 전달한다. 원본 체력·기력·공격 범위·이동·턴 처리·소리·애니메이션을 재사용한다. 양쪽 실행 결과의 체력·기력·위치·승패가 일치하는지 서버가 확인한다. 확인이 완료되어야 다음 라운드로 넘어간다. 이전 경기나 라운드 입력은 거부한다. 일치하지 않으면 대전을 종료하고 오류를 알린다.

경기 종료 후 원본 승패 연출을 보여 주고 양쪽 캐릭터 선택으로 돌아간다. 방과 호스트 설정은 유지하되 체력·기력·추가카드·선택·준비·입력은 초기화한다. 연결이 끊어지면 대전을 종료하고 남은 참가자에게 알린다. 싱글플레이 진행 데이터는 PvP에 사용하지 않는다.

배포물은 Windows용 실행 스크립트, 필요한 실행 환경, 웹 화면, 수정/원본 SWF, 원본 캐릭터 리소스, 재빌드용 소스, 테스트, 한국어 사용법이다. 실제 다른 물리 PC 및 외부 인터넷 환경을 테스트하지 못하면 검증 범위를 명시한다.

검증: 원본 태그의 바이트 동일성, 0~3장 지급, 모든 캐릭터 조합, 호스트 권한, 비공개 제출, 순서·중복·지연 메시지, 재선택, 연결 종료, 두 브라우저에서 실제 SWF의 카드와 전투 연출 및 상태 일치.
